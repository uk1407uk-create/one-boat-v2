# ONE BOAT V5 運営方針

## 今すぐ本番に採用

- 買う価値70以上を維持。
- 1R上限5,000円、100円単位、基本4点・最大6点を維持。
- 10分前再計算、8分前までにENTERまたはSKIPへ最終確定。
- ENTERかつ stake_total_yen > 0 の時だけ「✅予想完了」。
- 自信度100点を7軸で可視化する。
  - 軸の信頼度 25
  - 展示・スタート展示 15
  - 選手力・コース適性 25
  - モーター・足 15
  - 場・水面・風・潮 8
  - 当日流れ 8
  - オッズ妙味・期待値 4
- Confidence（予想しやすさ）と Value（妙味）を分離する。V5開始時点ではConfidenceはシャドー追跡で、ENTERの強制条件にはまだ使わない。
- 理論切替は1Rごとに変えず、同方向が2R連続した時に切替える。
  - 1号艇逃げ2R連続 → イン信頼＋当日流れ
  - 1号艇飛び2R連続 → イン飛び＋当日流れ
  - 1回だけ逆結果 → 据え置き
- オッズ分類を固定。
  - 3.0〜19.9倍：堅実｜壱−弐−参型
  - 20.0〜39.9倍：中穴｜直前気配＋ST型
  - 40.0〜59.9倍：中穴｜イン飛び外頭理論
  - 60.0〜99.9倍：狙い目｜直前強一致・1号艇型
  - 100.0〜199.9倍：高配当｜強イン高配当理論
  - 200倍〜：超高配当｜スコア66理論
- 3.0倍未満は本番対象外。
- 超高配当は高分散カテゴリとして扱い、強いカテゴリとはみなさない。

## シャドー追跡してから本番条件へ昇格

- 堅実A/Bランク。
  - A候補：軸、展示/ST、選手/コース、2・3着候補が強一致。
  - B：条件通過だが一部弱い。
  - まず30日追跡し、A/BでROI差が再現した場合のみENTER条件へ反映。
- 堅実オッズ帯を 3〜6.9 / 7〜9.9 / 10〜14.9 / 15〜19.9 に分解してROI・的中率を追跡。
- 堅実の1〜2点 / 3点以上を分離して点数効率を追跡。
- 超高配当を 200〜299 / 300〜499 / 500〜999 / 1000+ に分解して追跡。
- 自信度70以上を将来のENTER条件候補として記録するが、検証が終わるまでは強制しない。

## データが揃ってから採用

- 1R目の「風向・風速 × 直近14日結果」による初期理論選択。
- 潮汐、気温、水温、季節、水質の補正強化。
- 前走者相性、モーター×選手相性。
- BOX理論の本番採用。
- 20〜39.9倍での固定600円/900円配分。

理由：データ取得の安定性や再現性を確認せず本番ゲートへ入れると、過学習や一時的な偏りで収支を悪化させるため。

## 選手データ画面に載せる項目

データが取得できる項目だけを表示し、欠損値を推測で埋めない。

- イン逃げ / イン飛び信頼度
- 展示スリット評価
- 6艇の1着率・3連対率・ST順位・モーター評価
- 展示タイム・一周・まわり足・直線
- 当地成績・今節成績
- ONE BOAT評価
- 個人傾向タグ
- 手動 ◎○▲△×
- 手動 本線 / 抑え / メモ

## 予想の基本思想

単独理論1個では買わない。イン信頼、場別イン、ST、展示、一周、直線、モーター、選手コース別、当日流れなど、複数材料が同じ方向を向いた時に強くする。反対材料が出た場合は減点する。
