# ONE BOAT V5.1 運営方針

## 本番固定ルール

- 買う価値70以上。
- 1R上限5,000円、100円単位、基本4点・最大6点。
- 10分前再計算、8分前までにENTERまたはSKIPへ最終確定。
- ENTERかつ stake_total_yen > 0 の時だけ「✅予想完了」。
- 3.0倍未満は本番対象外。
- 理論サンプル40未満はWATCH。
- 理論ROI 100%未満はSTOP、100〜114.9%はWATCH、115%以上を本番採用基準。
- 穴系（狙い目・高配当・超高配当）は1日最大5R。
- 超高配当200倍以上は穴スコア66以上を必須とし、未取得はWATCH、66未満はSKIP。

## 自信度100点の7軸

1. 軸の信頼度 25
2. 展示・スタート展示 15
3. 選手力・コース適性 25
4. モーター・足 15
5. 場・水面・風・潮 8
6. 当日流れ 8
7. オッズ妙味・期待値 4

Confidence（予想しやすさ）と Value（妙味）は分離する。Confidence 70ゲートは30日検証が終わるまでシャドー追跡し、現時点では単独のENTER条件にしない。

## 配当帯と6理論

- 3.0〜19.9倍：堅実｜壱−弐−参型
- 20.0〜39.9倍：中穴｜直前気配＋ST型
- 40.0〜59.9倍：中穴｜イン飛び外頭理論
- 60.0〜99.9倍：狙い目｜直前強一致・1号艇型
- 100.0〜199.9倍：高配当｜強イン高配当理論
- 200倍〜：超高配当｜スコア66理論

超高配当は高分散カテゴリであり、ROIが高いだけで「強い」と判定しない。

## 理論切替

同一場で1号艇逃げが2R連続した場合は「イン信頼＋当日流れ」、1号艇飛びが2R連続した場合は「イン飛び＋当日流れ」に切り替える。1回だけ逆方向の結果が出ても切り替えない。

## V5.1で本番ロジックへ追加した補助条件

以下は単独でENTERさせず、既存の選手・展示・ST・モーター・Value判定を補助する。

- 1R目：風向・風速 × 直近14日類似条件の結果を初期理論の補助に使う。類似サンプル5件未満は採用しない。
- 潮汐：海水・汽水場だけ補助点に使う。淡水場では使わない。
- 気温・水温：モーター・場特性と組み合わせた評価値が取得できる場合だけ使う。
- 前走者モーター気配：モーター評価の補助に使う。
- モーター×選手相性：機力評価の補助に使う。

正方向の補助加点は、ベースValueが65以上かつ同方向の補助材料が2つ以上ある時だけ有効にする。補助材料1個だけではENTERへ昇格させない。反対材料は減点に使う。補助加減点は最大±6点に制限する。欠損値は推測で埋めない。

## ライブ予想の最終安全弁

本番の `/api/live/predict` は上流予想をそのまま表示せず、V5.1ローカル判定を通す。

ENTERに必要な条件：
- 上流 `purchase_allowed=true`
- production_picks が1点以上ある
- V5.1ローカル判定がENTER
- stake_total_yen > 0
- Value/ROI/サンプル/穴上限/超高配当ガードを通過

どれかを満たさない場合は購入不可。8分前最終判定時はENTERできなければSKIPとする。買い目は最大6点、合計投資額は5,000円以内に制限する。

## 内部追跡

- 堅実A/B：Aは軸・展示/ST・選手/コース・2/3着候補が強一致、Bは一部弱い。30日追跡後に差が再現した場合のみ本番条件へ昇格。
- 堅実オッズ帯：3〜6.9 / 7〜9.9 / 10〜14.9 / 15〜19.9。
- 堅実の点数効率：1〜2点 / 3点以上。
- 超高配当：200〜299 / 300〜499 / 500〜999 / 1000+。

## 選手データ画面の内部仕様

データが取得できる項目だけを保持し、欠損値を推測で埋めない。

- イン逃げ / イン飛び信頼度
- 展示スリット評価
- 6艇の1着率・3連対率・ST順位・モーター評価
- 展示タイム・一周・まわり足・直線
- 当地成績・今節成績
- ONE BOAT評価
- 個人傾向タグ
- 手動 ◎○▲△×
- 手動 本線 / 抑え / メモ

## まだ本番強制しないもの

- Confidence 70を単独の購入ゲートにすること。
- BOX理論の自動本番採用。
- 20〜39.9倍の固定600円/900円配分。

## 原則

単独理論1個では買わない。イン信頼、場特性、ST、展示、一周、直線、モーター、選手コース別、当日流れ、風・潮・温度、オッズ妙味など複数材料が同じ方向を向いた時に強くする。反対材料が重なる場合は減点または見送りとする。
